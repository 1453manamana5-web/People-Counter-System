# People-Counter-System

次世代人数カウントシステム（独立開発版）。

管理アプリ、入口・出口の計測アプリ、Luxnoraを独立した環境で開発します。
既存QRシステムの認証・データ・設定は引き継ぎません。

独立版の開発中です。専用Firebase接続設定および管理者認証を実装済み。Firestoreルールの公開、GitHub Pagesの初回公開、実機・実通信確認が完了するまでは本番運用しません。設定手順は [バックエンド構築](docs/backend-setup.md) を参照してください。

秘密鍵、管理者情報、来場記録、カメラ映像はリポジトリに保存しません。
