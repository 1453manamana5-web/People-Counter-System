# Apeir α-03〜α-05 研究記録

基準は正式リポジトリの `main` `ebb658b` と、α-02の重みがある `luxnora/v4-integration` `34a71a1`。研究ブランチは後者を起点とした。実装・学習・評価は `research/apeir/evolution` 内で完結する。

## Apeir World

Gymnasium上で1台の受付端末を模擬する。行動は待機、同期、カメラ復旧、認識処理復旧、人間への照会。障害があると計測漏れや未送信が発生し、同期によって未送信キューが減り、復旧を試みると以後の状態が変わる。復旧確認が2ステップ続くと終了し、1エピソードは最大14ステップ。最後の4観測には通信途絶による古い状態や欠損が含まれる。内部の障害、恒久故障、残件数、行動参照ラベルは教師生成と採点にだけ使う。

現行受付の `luxnora-core.mjs` と `app.js` から、復旧の許可、表示中、追跡中の保留、再試行の制限、再開後の連続確認を抽象化した。現行の管理画面からの復旧確認は3推論フレームと750 msの経過が必要で、試行予算も実時間で管理する。仮想環境では1試行と2ステップに簡略化している。同期は `ledger-ui.mjs` の端末内記録と送信待ちを抽象化した。画像認識、組み合わせた入口・出口、実回線、個人識別、本番認証はシミュレートしていない。安全ゲートはモデル出力とは別に確認し、状態不足のまま復旧を求めた場合は人への確認に置き換える。

## 各世代の学習

- **α-03**。MLP、2層GRU、2層LSTMで、行動、4種類の障害、異常の有無、次の観測後に異常が残る見込みを同時に学習。2,200エピソードの5,486判断で各10エポック。障害を複合させた検証400エピソードの1,300判断で温度校正と異常検出しきい値を選択した。検証用の重み付きリスクが最少だったGRUをα-03の代表にした。次状態ヘッドの出力は学習時の行動混合に対する予測。
- **α-04**。PPOとDQNに、欠損が少ない単独障害、欠損のある単独障害、複合障害の3段階を各8,192ステップ学習させた。合計49,152ステップで、100万は長期目標。長い未復旧、計測漏れ、不要・拒否操作、不適切な照会を報酬に反映した。検証エピソード平均報酬はPPO -3.847、DQN -2.573で、統合モデルの候補はDQN。独立評価では両方式とも実際の復旧操作を0件しか選ばず、単独での採用を見送った。照会でエピソードが終了することと、復旧操作が許される観測が比較的少ないことが、介入しない方策を学びやすくした可能性がある。原因診断は別のルール経路を同時に測定している。
- **α-05**。軽量ルール、α-03 GRUの診断と予測、α-04 DQNの行動候補を段階的に呼び出す。ルーターは別の学習1,200エピソード（2,967判断）、校正320エピソード（997判断）。候補間の損失差で難しい判断を重くし、異常を見逃す場合にコストを加えた。エピソード内に直前の行動、予測リスク、経過を保持する。最終の行動は独立ゲートで確認する。パラメーターは運用時に更新しない。

## 選択と失敗分析

- α-03 GRUの未知構成の重み付き誤りは202.33点で最小。判断正答率は80%を超え、α-02より見逃しが10件少なかった。原因集合の一致率には改善余地があり、独立ゲートがGRUの操作候補を31件差し替えた。
- α-05は未知構成の62.49%で軽量ルールのみを使った。確認率を減らし、復旧率もGRU単体より上がったが、20件の見逃しでα-02より悪化した。正答率上昇より見逃し抑制を優先し、現時点の研究代表にはGRUを選ぶ。
- α-05でエピソード記憶を無効にすると見逃しは36件。常に専門モデルまで呼ぶと1件。RL経路は独立評価で0回選ばれ、RLを読み込まない構成でも判断と復旧結果は同一だった。次の統合候補ではRLを常駐させず、軽量ルールを使う条件を検証用データで設計し直し、別の評価セットで確認する。

## 再現と再開

Python 3.12、CPU版PyTorch 2.8.0、Gymnasium 1.2.3、Stable-Baselines3 2.7.1を利用した。CPU版のPyTorchを公式ホイールから選べる。以下はこのディレクトリで実行する。

```sh
python -m pip install -r requirements.txt
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
python -m unittest -v test_world
python supervised.py --out artifacts --epochs 10
python reinforcement.py --out artifacts --algo ppo --steps 24576
python reinforcement.py --out artifacts --algo dqn --steps 24576
python integrated.py --out artifacts
python evaluate.py --out artifacts
```

各学習スクリプトの `--resume` に対応。α-03は完了エポックの重み・最適化器・乱数状態、α-04は完了段階のモデルと最適化器、DQNの経験バッファを保存する。α-04の環境内の途中のエピソードは段階再開時に再現しない。DQNの別の短い試験で、768ステップの保存から1,536ステップまで実際に再開した。α-05はルーターの完了した学習結果から再学習を継続できる。ファイル名が同じ専門モデルを上書きした場合はルーターも再学習する。チェックポイントは信頼できる研究ブランチのものを使う。
