## 再現手順

リポジトリのルートで実行する。検証にはPython 3.12、PyTorch 2.8.0 CPU、NumPy 2.3.5、Node.js、Chromiumを使用した。Ruriの初回取得にはネットワークが必要。学習、評価、Ruriの特徴抽出はローカルで実行する。

```sh
python -m venv /tmp/luxnora-v52-venv
. /tmp/luxnora-v52-venv/bin/activate
python -m pip install numpy==2.3.5
python -m pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cpu
export OPENBLAS_NUM_THREADS=1
study=research/luxnora-v52
run=$(mktemp -d)
python -m unittest discover -s "$study"
python "$study/generate.py" --out "$run/data"
python "$study/train.py" --data "$run/data" --out "$run/artifacts"
python "$study/additional-eval.py" "$run/data" "$run/artifacts"
npm install --prefix "$run/browser" playwright-core
playwright="$run/browser/node_modules/playwright-core/index.mjs"
node "$study/browser-probe.mjs" "$playwright" /usr/bin/chromium "$run/artifacts"
node scripts/prepare-luxnora-model.mjs "$run"
node "$study/ruri-features.mjs" "$playwright" /usr/bin/chromium "$run/luxnora-assets" "$run/data" "$run/ruri.json"
python "$study/additional-eval.py" "$run/data" "$run/artifacts" --ruri-features "$run/ruri.json"
```

同梱した圧縮コーパス、比較結果、学習済みの全候補、軽量版int8が研究ディレクトリにある。浮動小数点のブラウザ資産と照合データは上の手順で再生成できる。次に独立評価を更新する際は、改善に使用したケースを回帰用に移し、自然な複数ターンと目的構造の異なる複合依頼を新規に作成する。 [データと重み](../research/luxnora-v52)
